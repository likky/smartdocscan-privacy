🔒 隐私政策

智能文档扫描 · SmartDocScan

概述

智能文档扫描（以下简称"本软件"）高度重视用户隐私。 本隐私政策说明我们在您使用本软件时如何收集、使用和保护信息。

本软件是一款离线桌面应用，核心功能 — 文档扫描、OCR 文字识别、版式分析、表格识别、公式识别 — 全部在您的设备本地完成，不会将您的文档或图片上传到任何远程服务器。

我们收集的信息

✅ 我们不收集的内容

  • 文档内容 — 您扫描或导入的所有文档、图片、PDF 均仅在本地处理，不会上传至任何服务器。
  • 个人身份信息 — 我们不收集姓名、邮箱、电话、地址等个人信息。
  • 位置信息 — 我们不获取 GPS 或网络定位信息。
  • 设备中的其他文件 — 我们仅访问您主动选择导入的文档/图片文件。

📋 自动收集的少量数据

  • 崩溃诊断数据 — 如果应用发生崩溃，操作系统可能自动生成崩溃日志。这些日志存储在您设备本地，不会自动发送给我们。
  • Microsoft Store 许可数据 — 如果您通过 Microsoft Store 安装本软件，Store 会验证您的试用/购买状态。这是 Microsoft 平台的标准行为，我们不存储或转发这些数据。

数据使用方式

  • 本地 OCR 推理 — 文档识别使用内置 AI 模型在本地 CPU/GPU 上运行，不需要网络连接。
  • 仅本地存储 — 识别结果和导出的文件仅保存到您指定的本地路径。本软件不使用云端存储。
  • 许可验证 — 仅通过 Microsoft Store 官方 API 验证试用/购买状态，不传输任何文档数据。

网络使用

本软件仅在以下情况访问网络：

  • Microsoft Store 许可验证 — 查询试用剩余天数和购买状态。
  • 购买操作 — 当您主动点击"购买"按钮时，打开 Microsoft Store 完成支付。

核心 OCR、扫描、识别功能均离线运行，无需网络连接。

第三方服务

本软件不集成任何第三方分析 SDK、广告 SDK 或数据统计服务。

Microsoft Store 许可验证使用了 Windows 系统内置的 Windows.Services.Store API，该 API 的数据处理受 Microsoft 隐私声明 约束。

数据安全

所有文档处理在本地完成，数据不会离开您的设备，从根本上避免了传输和存储过程中的泄露风险。 建议您通过操作系统提供的全盘加密（如 BitLocker / FileVault）保护本地文件。

儿童隐私

本软件不针对 13 岁以下儿童，不会故意收集儿童的个人信息。

政策更新

本隐私政策可能不时更新。更新后的版本将随软件新版本一同发布，并在本页面更新。
